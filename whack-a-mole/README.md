# 打地鼠（Whack-a-Mole）

純前端小遊戲，支援桌機與行動裝置觸控。目標是在限定時間內，盡量點擊冒出來的「地鼠」，而不要打到「小雞（朋友）」。

## 功能
- 棋盤尺寸：3×3、4×3（直立時自動 3×4）、4×4
- 難度：容易／普通／困難（控制出現間隔與停留時間）
- HUD：分數、時間、命中次數／嘗試次數、結束統計

## 操作
- 滑鼠點擊或螢幕觸控洞格即可
- 「地鼠」顯示為棕色外框＋🐭；「小雞」為藍色外框＋🐥
- 打到地鼠 +1；打到小雞 -1；空點不扣分

## 檔案
- `index.html`：頁面與控制選單
- `styles.css`：棋盤與角色樣式
- `main.js`：遊戲狀態、出現邏輯、計分與倒數

## 執行
直接打開 `little_games/whack-a-mole/index.html`（或從 `arcade/index.html` 進入）。
