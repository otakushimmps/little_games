# 五子棋（Gomoku）

15×15 棋盤的五子棋，提供多段電腦強度、悔棋與對局重播等功能。

## 功能
- 難度：新手／容易／一般／困難／高手
- 先手選擇：黑或白
- 重播控制：上一手、下一手、播放／暫停
- 狀態面板：當前輪到、勝負結果

## 操作
- 滑鼠點擊或觸控在棋盤落子。
- 右側控制區可重新開始、悔棋與調整難度。

## 檔案
- `index.html`：頁面與控制項
- `styles.css`、`responsive.css`：棋盤樣式與響應式
- `main.js`：棋盤繪製、棋規、電腦對局與重播

## 執行
打開 `little_games/gomoku/index.html`（或從 `arcade/index.html` 進入）。
